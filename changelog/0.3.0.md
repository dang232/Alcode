## App

### New

- **Run graph:** the DAG panel reads the engine's own task records and merges them with the session snapshot, so a task that exists only as a record still appears with its id, status, verification and repair state.
- **Autonomous repair:** a failed task can be repaired and re-verified inside the same run, and the repair state shows beside the task instead of replacing its verdict.
- Code Mode: native grep, glob and edit tools let the agent search and change the workspace without a shell.

### Improvements

- Task rows carry what the record recorded: the failure reason, duration, model, execution mode and run counters.
- A task store that could only be read in part says so above the rows instead of looking complete.
- A cancelled or interrupted run reads as cancelled; it used to be recorded as completed.

### Fixes

- A node's verification claim is corrected after the task id is attached, so a task never reads Verified while its own record says otherwise.
- A project's own config can no longer point the task read at another project's store.
- Code graph: an index failure names its cause, and a healthy index is no longer reported as unavailable.
- Code search: glob patterns match the search scope, and a capped root scan still answers.
