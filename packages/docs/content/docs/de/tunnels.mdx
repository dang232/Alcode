# Tunnel

Ein Tunnel ist ein öffentlicher Link zu deinem Alcode, damit du ihn von einem normalen Browser in einem anderen Netzwerk aus erreichen kannst. Nutze `alcode tunnel`, um einen für eine laufende Instanz zu erstellen.

> Wenn du **deine eigenen Geräte** verbindest (die Mobile App, einen anderen Desktop), brauchst du normalerweise keinen Tunnel — [kopple sie](/connect-devices/) stattdessen und lass das Ende-zu-Ende-verschlüsselte [Private Relay](/private-relay/) den Zugriff von unterwegs ohne zusätzliche Einrichtung übernehmen.

## Voraussetzungen

Alcode startet das CLI des Tunnel-Anbieters auf deinem Rechner. Installiere zuerst den Anbieter, den du verwenden möchtest:

```bash
brew install cloudflared
brew install ngrok
```

Cloudflare Quick Tunnels können mit `cloudflared` laufen. Ngrok benötigt ein ngrok-Konto und ein Authtoken aus dem ngrok-Dashboard:

```bash
ngrok config add-authtoken <your-ngrok-token>
```

## Schnellstart

1. Starte Alcode:

```bash
alcode
```

Wenn du diesen Schritt überspringst, kann `alcode tunnel start` automatisch einen CLI-Server starten. Beim automatischen Start kannst du Serveroptionen wie `--port`, `--host`, `--lan`, `--ui-password` und `--api-only` mitgeben.

2. Starte einen Cloudflare-Tunnel:

```bash
alcode tunnel start --provider cloudflare --mode quick
```

Oder starte einen Ngrok-Tunnel:

```bash
alcode tunnel start --provider ngrok --mode quick
```

3. Status prüfen:

```bash
alcode tunnel status
```

Sobald der Tunnel aktiv ist, zeigt `status` eine öffentliche URL. Öffne sie oder scanne den QR-Code, um Alcode von überall aus zu erreichen.

Standardmäßig druckt Alcode in interaktiven TTY-Sitzungen einen QR-Code. Mit `--qr` erzwingst du die QR-Ausgabe, mit `--no-qr` deaktivierst du sie.

## Anbieter

- `cloudflare`: Quick-, Managed-Remote- und Managed-Local-Modi
- `ngrok`: Quick-Modus

## Verwaltete Modi

### Managed Remote

Verwende ein von Cloudflare verwaltetes Token und einen Hostnamen:

```bash
alcode tunnel start --provider cloudflare --mode managed-remote --token-file ~/.secrets/cf-token --hostname app.example.com
```

### Managed Local

Verwende eine lokale `cloudflared`-Konfiguration:

```bash
alcode tunnel start --provider cloudflare --mode managed-local --config ~/.cloudflared/config.yml
```

## Profile (managed-remote)

Ein wiederverwendbares Profil speichern:

```bash
alcode tunnel profile add --provider cloudflare --mode managed-remote --name prod-main --hostname app.example.com --token-file ~/.secrets/cf-token
```

Mit dem gespeicherten Profil starten:

```bash
alcode tunnel start --profile prod-main
```

## Nützliche Befehle

```bash
alcode tunnel providers
alcode tunnel ready --provider cloudflare
alcode tunnel ready --provider ngrok
alcode tunnel doctor --provider cloudflare
alcode tunnel doctor --provider ngrok
alcode tunnel stop --port 3000
```

## Hinweise zum Verhalten

- ein aktiver Tunnel pro Alcode-Instanz (Port)
- wenn auf derselben Instanz ein neuer Modus oder Anbieter startet, ersetzt er den vorherigen Tunnel
- das Erstellen eines neuen Verbindungslinks widerruft den vorherigen unbenutzten Link
- das automatische Starten des Tunnels bewahrt Server-Flags wie `--ui-password` und `--api-only` in den Instanzeinstellungen auf, die von Neustart-/Update-Flows verwendet werden
