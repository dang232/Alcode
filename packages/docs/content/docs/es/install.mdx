# Instalación

Elige la app que encaje con tu forma de trabajar:
Hay tres formas de ejecutar Alcode:

- app de escritorio para macOS, Windows y Linux
- app web que ejecuta la CLI, que puedes instalar como una app de teléfono (una PWA)
- extensión para VS Code, también para Cursor, Windsurf y Trae
- apps móviles para iPhone y Android, en beta pública

## Escritorio

Descarga la última versión desde la [página de descarga](https://openchamber.dev/download/) o desde [GitHub Releases](https://github.com/openchamber/openchamber/releases/latest) y ábrela. Para Linux hay `.deb`, `.rpm` y AppImage.

La app de escritorio trae su propia copia de [OpenCode](https://opencode.ai) (el agente de IA para código sobre el que funciona OpenChamber), así que no hay que instalar nada más.
Instala [OpenCode](https://opencode.ai) primero: Alcode se ejecuta sobre él.

## Web + PWA

La app web necesita [OpenCode](https://opencode.ai) y Node.js 24.14 o posterior en la máquina donde se ejecuta.

```bash
curl -fsSL https://raw.githubusercontent.com/dang232/Alcode/main/scripts/install.sh | bash
alcode --ui-password be-creative-here
```

Abre la URL que muestra la CLI (normalmente `http://localhost:3000`). Deberías ver la lista de sesiones de OpenChamber. Para tenerla a mano, usa la opción «Instalar» de la barra de direcciones del navegador y añádela como app.

## VS Code

Instala OpenChamber desde el [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber). Cursor, Windsurf y Trae lo instalan desde [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber). La extensión necesita [OpenCode](https://opencode.ai) instalado; después, la vista de OpenChamber se abre en la barra lateral.

## Móvil

Instala la app de iPhone con TestFlight o la app de Android desde la última versión, y luego emparéjala con tu ordenador. [Apps móviles y PWA](/es/mobile/) explica ambos pasos.
Abre la URL que imprime la CLI (normalmente `http://localhost:3000`). Deberías ver la lista de sesiones de Alcode. Para tenerlo a mano, usa la opción "Instalar" de tu navegador en la barra de direcciones para añadirlo como una app.
## Escritorio
Descarga la última compilación de escritorio desde la página de releases de GitHub o la página de descargas de Alcode. Ábrela e inicia sesión con tu flujo de trabajo habitual de OpenCode.
Instálala desde el VS Code Marketplace e inicia sesión con tu flujo de trabajo habitual de OpenCode. La vista de Alcode se abre entonces en la barra lateral.
