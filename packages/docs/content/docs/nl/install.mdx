# Installeren

Kies de app die past bij hoe u werkt:
U kunt Alcode op drie manieren gebruiken:

- als desktopapp voor macOS, Windows en Linux
- als webapp via de CLI, ook te installeren als app op uw telefoon via een PWA
- als VS Code-extensie, ook voor Cursor, Windsurf en Trae
- als mobiele app voor iPhone en Android, in openbare bèta

## Desktop

Download de nieuwste versie van de [downloadpagina](https://openchamber.dev/download/) of van [GitHub Releases](https://github.com/openchamber/openchamber/releases/latest) en open die. Voor Linux zijn er `.deb`, `.rpm` en AppImage.

De desktopapp heeft een eigen exemplaar van [OpenCode](https://opencode.ai) aan boord (de AI-codeeragent waarop OpenChamber draait), dus u hoeft verder niets te installeren.
Installeer eerst [OpenCode](https://opencode.ai). Alcode bouwt daarop voort.

## Web en PWA

De webapp heeft [OpenCode](https://opencode.ai) en Node.js 24.14 of nieuwer nodig op de machine waarop hij draait.

```bash
curl -fsSL https://raw.githubusercontent.com/dang232/Alcode/main/scripts/install.sh | bash
alcode --ui-password be-creative-here
```

Open de URL die de CLI toont (meestal `http://localhost:3000`). U ziet dan de sessielijst van OpenChamber. Wilt u hem bij de hand hebben, gebruik dan de optie "Installeren" in de adresbalk van de browser en voeg hem toe als app.

## VS Code

Installeer OpenChamber vanuit de [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.openchamber). Cursor, Windsurf en Trae installeren hem vanuit [Open VSX](https://open-vsx.org/extension/FedaykinDev/openchamber). De extensie heeft een geïnstalleerde [OpenCode](https://opencode.ai) nodig; daarna opent de OpenChamber-weergave in de zijbalk.

## Mobiel

Installeer de iPhone-app via TestFlight of de Android-app uit de nieuwste release en koppel hem daarna aan uw computer. [Mobiele apps en PWA](/nl/mobile/) beschrijft beide stappen.
Open de URL die de CLI toont, meestal `http://localhost:3000`. U ziet nu de sessielijst van Alcode. Via de optie 'Installeren' in de adresbalk van uw browser kunt u de webapp als app toevoegen.
## Desktop
Download de nieuwste desktopversie via de GitHub-releases of de downloadpagina van Alcode. Open de app en meld u aan zoals u gewend bent voor OpenCode.
Installeer de extensie via de VS Code Marketplace en meld u aan zoals u gewend bent voor OpenCode. De Alcode-weergave verschijnt vervolgens in de zijbalk.
