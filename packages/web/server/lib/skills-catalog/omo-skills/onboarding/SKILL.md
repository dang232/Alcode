# onboarding

Take a new user from zero to their first verified run.

## Process

1. Providers first: confirm one model provider answers (list models, no
   keyed spend beyond one probe), or route to Settings with the exact steps.
2. Tour the surfaces that matter for their work: sessions, skills catalog,
   agents catalog, and where evidence lands.
3. Do one tiny real task end to end (ask, change, verify) and capture its
   evidence, so the loop is learned by doing.
4. Leave them with the notepad habit: goal, findings, receipts.

## Rules

- Never clear or clone the user's real browser profile or credentials.
- Explain each step before doing it; stop on the first surprise.
